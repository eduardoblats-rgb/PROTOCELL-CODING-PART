# Code and data: spatial coupling of RNA folding states in nested coacervates

Computational models behind the manuscript *"Spatial coupling of RNA folding states in multiphase coacervates enables isothermal replication"*
(Eduardo Blat Sos). The hypothesis: a protocell with two nested coacervate phases of different net charge creates, through a single
Donnan equilibrium, a ~100-fold Mg²⁺ gradient. RNA folds and catalyses in the Mg-rich phase and its strands separate in the Mg-poor phase, so the
template–catalyst conflict of an RNA replicator is resolved in space instead of time.

> **Status:** theoretical / computational work. Nothing here is experimental evidence. See "Limitations" below.

## Quick start

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt          # ViennaRNA 2.7.2, numpy, scipy, matplotlib
./run_all.sh                             # redraws Figs 1B–6 from the shipped data (≈ 10 s)
./run_all.sh full                        # recomputes every simulation from scratch, then redraws (≈ 2 min on 2 cores)
```
Outputs go to `output/` (the shipped `figures/` folder is never overwritten). Tested with Python 3.13 on Linux. The shipped `figures/` were drawn with the Inter font; if it is not installed, matplotlib falls back to DejaVu Sans and the figures look the same apart from the typeface.
Figure 1A is a conceptual schematic and is not generated by this code.

## Model in brief

* **Folding / melting:** ViennaRNA 2.7.2 partition function; the inner coacervate phase is represented by a soft-constraint penalty δ per base pair
  (0.27 kcal/mol, calibrated to the FRET data of Choi et al. 2022; 0.10 for a weak prebiotic polycation).
* **Magnesium → salt mapping:** ViennaRNA has no Mg²⁺ parameters, so Mg²⁺ is treated as a monovalent-equivalent salt
  (3 mM Mg²⁺ ≈ 1 M NaCl, capped at 1.0 M; inner phase 0.1 mM ≈ 48 mM). Results depend on this mapping (see manuscript).
* **R3C kinetics:** helix energies from ViennaRNA plus one free offset J, calibrated so that one-phase growth equals the measured
  0.98 h⁻¹ at 42 °C, 25 mM MgCl₂ (Lincoln & Joyce 2009). Reproducing that rate is therefore a consequence of the calibration, not a test of the model.
* **Population level:** tau-leaping stochastic-corrector model (200 protocells), with parasites and a Moran-type competition.

## Limitations

* ViennaRNA predicts secondary structure only; tertiary contacts and real Mg²⁺ binding are not modelled.
* The Mg²⁺ gradient comes from an ideal Donnan equilibrium; ion condensation, Mg–phosphate binding and activity coefficients could make it much smaller.
* The R3C model has no thermal inactivation of the enzyme, so it cannot predict an optimal temperature and is not valid far above 42 °C.
* Inter-phase exchange rates of RNA are unmeasured; the speed-up in Fig 4 depends strongly on them.
* R3C helix sequences were read from the published scheme (Lincoln & Joyce 2009, Fig. 1B) and should be checked against the supplementary data.

## Data

`data/` holds the derived data used for the figures (see `data/README.md`). Ribozyme sequences come from RCSB PDB entries
5K7C (chain A), 5Y85 (chain B), 1HMH (RNA strand), 9A0V and 6G7Z (chain A).
